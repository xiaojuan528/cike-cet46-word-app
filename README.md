# 词刻 · 四六级随手背

本地可安装的移动端背单词应用，覆盖四级和六级考纲词表。

## 功能

- 四级、六级、全部三种学习范围
- 一屏一题、四选一释义
- 答后显示完整释义、英文解释和双语例句
- 自动记录每个单词的累计答错次数
- 错题本、错题搜索和专项复习
- 连续答对 3 次自动标记“已掌握”，并从随机学习池移除
- 已掌握词表支持搜索和重新加入学习
- 学习统计、正确率和级别进度
- 浏览器本地持久化，支持离线启动

## 在本机运行

在 PowerShell 中执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\start-app.ps1
```

也可以直接启动任意静态文件服务器，然后打开该目录。

## 数据

词汇数据来自 `data/words.json`，由整理后的四六级词汇 Excel 文档导出，共 7816 个词形。
